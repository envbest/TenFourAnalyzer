# TenFour Analyzer

TenFourのプレイをブラウザ内に記録し、ハンドのリプレイ・収支確認・PokerStars互換テキストの出力ができるChrome拡張機能です。

## 導入

**Chromeだけで利用できます。Git・Node.js・npmは不要です。**

1. [ビルド済みZIPをダウンロード](https://github.com/envbest/TenFourAnalyzer/raw/refs/heads/main/downloads/tenfour-analyzer.zip)します。
2. ZIPを展開し、中の `tenfour-analyzer` フォルダを任意の保存場所に置きます。このフォルダは利用中に移動・削除しないでください。
3. Chromeで `chrome://extensions` を開き、「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」から、展開した **`manifest.json` が入っている `tenfour-analyzer` フォルダ**を選びます。ZIPそのものは選びません。
5. TenFourに通常どおりログインし、TenFourのページを再読み込みします。
6. ブラウザの拡張機能メニューから **TenFour Analyzer** をクリックすると、記録画面が開きます。

通常利用に開発サーバーやリモートデバッグの設定は不要です。

## 記録と振り返り

1. 拡張機能を有効にしたブラウザでTenFourをプレイします。記録は初期状態で有効です。
2. 記録画面の「ハンド履歴」からハンドを選びます。
3. リプレイの矢印・スライダーでアクションを確認できます。メモ・ブックマークも保存できます。

画面上部に受信状況・保存イベント数・最終保存時刻を表示します。初回はTenFourの再読み込みと受信確認の手順を案内します。「新しいデータを待っています」は過去の受信実績があり、直近20秒間は対象データを受信していない状態です。ロビーでも表示されるため、接続エラーとは限りません。

「記録・データ管理」で記録の停止・再開、保存イベント数、最終保存時刻を確認できます。「デモを見る」は架空のハンドを表示する機能です。

### Fast Fold後の履歴・相手カードを補完する

TenFour側の **Hand History** で対象ハンドの詳細を開いてください。受信した履歴を既存の記録と照合し、残りのアクション・精算結果・開示された相手カードを取り込みます。補完できたハンドには「履歴で補完済み」と表示されます。

過去の履歴を一括取得する機能ではありません。プレイ中の記録がない場合や、開始スタックなどが不足する場合は、履歴詳細だけでは補完できません。

## テキスト出力

- **1ハンド**：対象を選び「このハンドを出力」→「テキストをコピー」または「この1件をダウンロード」。
- **複数ハンド**：チェックボックスで選択し「エクスポート」→「.txt をダウンロード」。未選択なら現在の絞り込み結果が対象です。

出力は英語のPokerStars互換形式です。通常卓の実ハンド1件で、GTO Wizardへの取り込み成功を確認済みです。その他のハンド形式はGTO Wizardでの確認が未実施です。自動送信は行いません。

データ不足や金額の不整合があるハンドは出力対象から除外されます。理由はハンド詳細の「確認事項」で確認できます。

## バックアップ・復元

「記録・データ管理」から操作します。

- **バックアップ**：受信原本・ハンド・メモをJSONファイルに保存します。
- **復元**：自分で保存したJSONファイルを選び、既存データに統合します（100 MB以下）。
- **原本から再処理**：保存済みの受信データからハンドを再構築します。メモ・ブックマークは保持します。更新後に既存の記録へ修正を反映したい場合に使います。

データは利用中のブラウザプロファイル内に保存されます。拡張機能の削除前や復元前にはバックアップしてください。現状の復元処理は更新日時が新しいハンドを優先するため、既存の完成済みハンドが不完全な内容で上書きされる場合があります。

バックアップにはプレイヤー名・UID・カード・メモなどが含まれます。共有する場合は内容を確認してください。

## 更新

1. プレイを終了し、「記録・データ管理」でバックアップを保存します。
2. 最新のビルド済みZIPをダウンロードして展開します。
3. 展開した `tenfour-analyzer` フォルダの中身を、**現在読み込んでいるフォルダへ上書き**します。
4. `chrome://extensions` のTenFour Analyzerの更新ボタンを押し、TenFourのページも再読み込みします。
5. 必要に応じて「原本から再処理」を実行します。

拡張機能を削除・再追加する必要はありません。以前 `dist` を読み込んでいた場合も、その `dist` 内へ上書きしてください。保存先を変えると別の拡張機能として扱われる場合があります。

## 困ったとき・対応状況

- **記録されない**：TenFourを開いているブラウザプロファイルで拡張機能が有効か、「記録停止中」になっていないかを確認し、プレイ終了後にTenFourを再読み込みしてください。
- **「データ不足」になる**：TenFourのHand Historyで対象の詳細を開いてください。未受信の情報は推測で埋めません。
- **保存エラーが続く**：現状は後続の記録も滞る場合があります。保存イベント数と最終保存時刻を確認してください。ページを閉じると未保存の待機データは失われます。
- **通常卓**：実記録で記録・履歴補完・単体出力を確認済みです。
- **Expert・プライベート卓、サイドポット**：模擬データで検証済みです。実卓データでの確認は未実施です。サイドポットは配分を確定できる場合のみ出力します。

## 開発用

ソースから変更・ビルドする場合のみ、Git・Node.js 20以上・npmが必要です。配布ZIPの作成にはPython 3も使用します。

```bash
git clone git@github.com:envbest/TenFourAnalyzer.git
cd TenFourAnalyzer
npm ci
```

```bash
npm run dev    # UIプレビュー
npm test       # 自動テスト
npm run check  # 型チェック
npm run build  # 拡張機能をdistにビルド
npm run package # ビルドしてdownloads/tenfour-analyzer.zipを作成
```

UIプレビューは拡張機能とは保存領域が別です。実際のプレイ記録には、ブラウザへ読み込んだ拡張機能を使ってください。

配布時はテストを実行し、`npm run package` で作成したZIPをソースと一緒にコミットしてください。ZIPにはビルド済み拡張機能とREADMEだけが入り、個人の記録やブラウザプロファイルは含まれません。
